# 화면 문구 지침

범위: `ui/`에 쓰는 한국어 문구.
여는 때: 화면 문구를 새로 쓰거나 고칠 때.
다루지 않는 것: 화면 구조(코드 `ui/src/`).
전제: 기준은 하나 — 독자가 이미 쓰는 말인가. 새 말이 필요하면 여기 먼저 적는다.

| 쓰지 않는 말 | 쓰는 말 | 자리 |
|---|---|---|
| 상주 토큰 | 토큰 | 열 머리. 펼침 첫 줄에 「세션마다 실리는 양」 |
| 실측 / 추정보정 / 추정 / 측정 불가 | 측정값 / 추정값(보정) / 추정값 / 측정 안 됨 | 펼침 |
| 조작 | 끄기 | 열 머리 |
| 끄기 의도 / 끄기 예정 / 처리됨 / 되돌림 | 끄기 표시 / 끄기 예정 / 꺼짐 / 복구됨 | 버튼·뱃지 |
| 낡음 · 「파일이 바뀌었다」 | 판정 뒤 변경됨 | 판정 칸 뱃지 |
| 본문이 상주분의 10배를 넘는다 | 본문이 훨씬 크다 | 이름 옆 표시의 title |
| 측정 불가 — 실리는 것은 출력 | 훅은 출력만 실려 측정하지 않음 | 훅 행 |
| dir-scan / 실측 표본 | 폴더 스캔 / /context 측정 | 출처 |
| 재고 · 실측 표본 (머리말) | 재고 갱신 · 측정 | 머리말 |

하네스 · 양쪽 · CLI만은 화면에서 뺐다(열 폐기, 2026-08-22). 그대로 두는 말: 규칙 · 스킬 · 명령 · 에이전트 · 훅 · MCP · 메모리 · 판정(Keep / Improve / Update / Retire / Merge into X는 영어 그대로).
