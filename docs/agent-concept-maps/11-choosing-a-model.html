모델을 쓸까

순위표 두 개를 나란히 놓으면 서로 반대 이야기를 해요. 한쪽에서는 Claude가 위고 다른 쪽에서는 GPT가 위입니다. 둘 다 맞는데 재는 것이 다르기 때문이고 그 어긋남이 고르는 기준이 돼요.

먼저 이름부터

Sol, Terra, Luna는 별개의 모델이 아니에요. OpenAI의 GPT-5.6 한 가족의 세 등급입니다. 플래그십이 Sol, 균형이 Terra, 저가가 Luna예요. 셋 다 같은 날 나왔고 컨텍스트 창도 지식 컷오프도 같습니다.

두 순위표가 서로 반대로 나온다

Claude Opus 5와 Gemini 3.7 Flash는 가로축 지표에 값이 없어서 오른쪽 칸에 세로 위치만 맞춰 두었어요. 숫자는 Artificial Analysis 두 지표, 2026-08-29 스냅숏입니다.

그림의 본체는 Fable 5와 Sol이 서로 엇갈린 자리예요. 한 번에 옳은 답을 내놓는 쪽은 Claude가 앞서고 도구를 돌려 일을 끝까지 마치는 쪽은 Sol이 앞섭니다. Claude Opus 5는 세로에서 제일 높은데 가로 지표에는 값이 없어서 나란히 놓지 못했어요.

두 축을 나눠 놓고 보면 순위표를 놓고 벌어지는 말싸움이 대체로 축 혼동이라는 게 보여요. 「어느 모델이 제일 똑똑하냐」와 「어느 모델에게 맡기면 일이 끝나 있냐」는 다른 물음입니다.

GPT-5.6 값은 전부 할인가

정가는 Sol $5/$30, Terra $2.50/$15, Luna $1/$6이에요. Sol의 할인은 최소 2026-11-21까지 유효합니다. 2차 매체가 적어 둔 값은 정가인 경우가 많아서 어긋나 보일 수 있어요.

272K를 넘기면 할증

입력이 272,000 토큰을 넘으면 그 요청 전체가 입력 2배·출력 1.5배로 매겨져요. 일부만 두 배가 되는 게 아니라 요청 하나가 통째로요. (OpenAI 문서 인용이되 2차 매체 경유로 확인했어요.)

Gemini의 $0.75는 도입가

2026-12-31까지고 2027-01-01부터 $1.50/$7.50으로 두 배가 돼요. 싸다는 이유로 고르는 자리라면 이 날짜가 판단에 들어갑니다.

왜 표마다 순위가 뒤집히나

특히 잘못 읽히기 쉬운 자리

먼저 SWE-bench Verified에 GPT-5.6이 없는 것은 점수가 낮아서가 아니에요. OpenAI가 GPT-5.6을 발표하면서 이 벤치를 아예 제출하지 않았습니다. GPQA, AIME, MMLU, ARC-AGI-2, FrontierMath도 같이 빠졌어요. 표에 없는 것을 「낮다」로 읽으면 안 됩니다. 덧붙이면 이 벤치는 프런티어 모델들이 96% 근처로 몰려 있어서 상위권끼리는 1점 안쪽 차이예요.

다음으로 Terminal-Bench 숫자는 하네스를 적지 않으면 뜻이 없어요. 위 표에 같은 벤치가 세 줄로 나뉜 이유가 그거예요. Vals AI 쪽에는 조건이 하나 더 붙습니다 — Claude 모델이 거절을 내면 Opus 4.8로 되물려 실행하는데, Opus 5에서 그렇게 처리된 9건을 실패로 세면 84.64%가 81.27%로 내려가요. Claude 수치를 옮겨 적을 때는 이 조건을 같이 적어야 합니다.

커뮤니티에서 반복해서 나오는 이야기

Sol은 크게 쓰고 과하게 고친다

같은 과제에서 Sol이 내놓은 코드가 Fable 5의 세 배 크기였다는 보고가 있어요. 릴리즈 감사에서는 Sol 계열이 400건 가까이 지적한 반면 Fable 5는 70건 남짓이었고 이후 지적 대부분이 기각됐습니다7.

OpenAI 시스템 카드도 같은 방향으로 적어요. Sol이 이전 세대보다 목표를 집요하게 좇고 요청하지 않은 행동을 시도할 수 있다고요.

토큰당 값보다 해결당 값

CodeRabbit이 TypeScript·Go·Python·JavaScript·Rust로 100건 넘는 장기 과제를 돌렸어요. Sol은 63.7%를 통과하고 과제당 평균 20,968 출력 토큰을 썼고, Terra는 40.7%를 통과하는 데 완료당 55,594 토큰을 썼습니다8.

토큰 단가는 Terra가 절반인데 일을 끝내기까지 든 값은 Terra가 더 컸어요. 단일 조직의 측정이라는 점은 감안해야 하고요.

출력이 입력보다 여섯 배 비싸다

Codex의 크레딧 요금표에서 Sol은 출력 100만 토큰에 750크레딧, 입력에 125크레딧이에요. 사용량이 빨리 닳는다고 느낀다면 대개 출력 쪽입니다.

Terra를 xhigh로 돌려 5시간 창을 몇 분 만에 태웠다는 신고9도 있지만 답변 없는 단일 보고예요. 확인된 건 「출력이 비싸다」는 구조뿐입니다.

둘을 같이 쓰는 게 기본형

어렵고 모호한 것과 설계는 Claude에게, 범위가 정해진 구현은 GPT-5.6에게 맡기고 Codex를 엄격한 리뷰어로 붙이는 조합이 여러 곳에서 반복돼요. 커뮤니티 정리라 측정은 아니지만 앞의 두 축이 갈리는 것과 방향이 같습니다.

결국 세 자리

대량 구현과 일상 작업 — GPT-5.6 Sol, medium이나 high

Coding Agent Index에서 Sol 80이 Fable 5 77.2보다 위고 Terminal-Bench 2.1 리더보드에서도 앞섭니다. 장기 과제 통과율과 완료당 토큰도 Terra를 눌렀어요.

여기서 Terra는 함정이에요. 단가가 절반이니 대량 작업은 Terra라고 생각하기 쉬운데, 긴 작업에서는 완료까지 든 값이 Terra 쪽이 더 컸습니다. Terra의 자리는 범위가 분명하고 짧게 끝나는 구현이에요. Terra를 xhigh로 돌리는 것은 피하는 편이 좋고요.

설계와 리뷰와 어려운 디버깅 — Claude Opus 5

종합 지능 1위 63.0%, SWE-bench Verified 1위 96%. 값도 Sol과 비슷해요($5/$25 대 $4/$20). 어렵고 모호한 것은 Claude에게 준다는 커뮤니티 습관과도 맞고요.

Fable 5($10/$50)는 스스로 오래 도는 세션처럼 좁은 자리로 미뤄 두는 편이 무난해요. 다만 이 판단은 확정도가 낮습니다 — Opus 5와 Fable 5는 대부분 지표에서 오차 범위 안이고, 긴 세션에서 어느 쪽이 더 버티는지는 재 본 자료를 찾지 못했어요.

싸게 많이 — Gemini 3.7 Flash를 먼저, Luna는 조건부

Luna가 $0.20/$1.20로 제일 싸지만 롱컨텍스트 회상이 41.3%예요. Sol·Terra가 90% 안팎인 것과 자릿수가 다릅니다. Luna에게는 긴 입력을 주면 안 돼요. 짧은 입력에 결과가 예측되는 추출·분류·변환까지가 자리예요.

저가대에서 판단이 필요한 일이라면 Gemini 3.7 Flash가 낫습니다. $0.75/$3.75에 종합 지능 56.0으로 Terra(55.0)보다 위고 Terminal-Bench 2.1도 85.8%예요10. 출력 속도는 186개 모델 중 1위(340.1 tok/s)고요. 단서가 둘 붙어요. 12/31 이후 값이 두 배가 되고 Codex CLI 안에서는 직접 고를 수 없습니다.

Codex CLI에서 고르기

세션 중에는 /model을 치면 팝업에서 모델과 추론 강도를 함께 고를 수 있어요. 기본값으로 굳혀 두려면 설정 파일에 적습니다.

model = "gpt-5.6-sol"
model_reasoning_effort = "high"

model_reasoning_effort에 안전하게 적을 수 있는 값은 low, medium, high, xhigh 넷이에요. API 모델 문서에는 none과 max까지 여섯 단계가 있지만 CLI 레퍼런스11는 넷만 적고 있어서, 나머지 둘이 CLI에서 먹히는지는 문서로 판정할 수 없어요. 아무것도 적지 않으면 보통 Sol에 medium이 붙습니다. 프로필을 여러 벌 두고 --profile <이름>으로 갈아 끼우는 방법도 있어요.

OpenAI가 붙여 둔 등급 안내는 이래요. Sol은 모호하고 어렵고 값이 큰 일 — 복잡한 코드 변경, 심층 조사, 다듬어야 하는 문서. Terra는 표준적인 추론과 도구 사용이 필요한 일상 작업. Luna는 결과가 예측되는 반복 작업. 추론 강도는 목표를 이루는 가장 낮은 단계에서 시작하라고 적혀 있고요.

2026-08-31에 GPT-5.5, GPT-5.4, GPT-5.4 mini가 Codex에서 은퇴해요. 설정 파일에 gpt-5.4가 적혀 있으면 gpt-5.6-terra로, gpt-5.4-mini는 gpt-5.6-luna로 옮기라는 것이 안내된 대응입니다. GPT-5.6을 쓰려면 codex-cli 0.144.0 이상이 필요하고요.

Claude Code에서는

마찬가지로 /model이에요. Opus 5(1M 창)가 기본 권장이고 Claude Code 2.1.219 이상에서 쓸 수 있어요. Fable 5는 기본이 아니라 /model fable로 골라야 합니다12. 창을 얼마나 쓸지의 기준은 10장에 있어요.

기억해 둘 한 줄. 순위표 하나로 고르지 말고 두 축으로 갈라요 — 한 번의 답이 옳아야 하는 일은 Claude 쪽, 도구를 돌려 끝까지 가야 하는 일은 Sol 쪽. 그리고 단가가 아니라 일이 끝나기까지 든 값으로 셉니다.
